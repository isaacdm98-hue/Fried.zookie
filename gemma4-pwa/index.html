Gemma 4 · on device

Run Gemma 4 fully on your phone

This loads a Google Gemma 4 mobile model (LiteRT .task / .litertlm) and runs it in the browser on WebGPU — no server, nothing leaves your device. Pick the model file once; it's saved locally and reloads instantly next time.

1 · Get a model file

Download a browser-ready Gemma 4 model (accept Google's licence on the page), e.g.:

• litert-community / gemma-4-E2B-it-litert-lm (~1 GB, fits phones)
• or any *-web.task from litert-community

Look for a file ending in -web.task or -Web.litertlm — those are converted to run in the browser.
